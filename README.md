# CH-ArmorHide

방어구(투구 / 갑옷 / 바지 / 신발)가 **어떤 이유로든 사라지지 않도록** 지켜주는 Paper 플러그인입니다.

- 서버: Paper 1.21+ / Java 21
- 선택 플러그인: 없음 (CH-TradeLock 과 함께 써도 충돌하지 않음)

## 기능

| 기능 | 설명 |
|---|---|
| 사망 시 방어구 유지 | 인벤세이브권이 있든 없든 죽어도 입고 있던 방어구는 떨어지지 않고, 리스폰 후 같은 칸으로 돌아옵니다. |
| 소실 자동 복구 | 직접 벗지 않았는데 입고 있던 방어구가 빈칸이 되면(상점 구매, 랜덤박스, 우편함, 다른 플러그인 등) 바로 다시 입혀줍니다. |
| 원인 기록 | 복구가 일어나면 그 순간 열려 있던 창 / 직전 명령어 / 직전 클릭을 `restore.log` 에 남기고 OP 에게 알립니다. |

### 사망 처리
- 인벤토리가 통째로 유지되는 사망(CH-TradeLock 의 보호 월드 / 초심자의 행운 / 인벤세이브권)에서는 방어구도 그대로라 아무것도 하지 않습니다.
- 그 외 사망에서는 방어구를 드롭에서 빼서 `pending.yml` 에 보관했다가 리스폰 2틱 뒤에 돌려줍니다. (타이틀 화면으로 나가거나 서버가 재시작돼도 다음 접속 때 돌려줌)
- 소멸 저주가 붙은 방어구는 기본적으로 그대로 사라집니다. (`respect-vanishing-curse`)
- 다른 플러그인(CH-TradeLock 의 거래불가 보호 등)이 이미 돌려주도록 지정한 방어구는 건드리지 않습니다. (복사 방지)

### 소실 복구 — 복구하지 않는 경우
- 내 인벤토리에서 방어구 칸을 직접 클릭해 벗었을 때 (쉬프트클릭, 숫자키, 더블클릭 포함)
- 내구도가 다해 부서졌을 때
- 사망했을 때 / 크리에이티브 / 관전 모드
- 같은 아이템이 인벤토리나 커서에 있을 때 (옮겨진 것이므로 복사 방지)
- 관리자가 다른 사람 인벤토리를 직접 수정할 때 (`/invsee` 등 일부), `legit-commands` 의 명령어(`/clear` 등) 직후
- 10초 안에 5번 넘게 복구해야 하면 다른 플러그인과 충돌 중인 것이므로 잠시 중단하고 OP 에게 알림

## 명령어 / 권한

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/armorhide reload` (`/방어구보호`) | 설정 리로드 | `charmorhide.admin` |
| `/armorhide allow <닉네임> [초]` | 그 시간(기본 30초) 동안 해당 유저의 방어구 복구를 멈춤 (관리자가 일부러 빼야 할 때) | `charmorhide.admin` |

## 설정 (`config.yml`)

| 키 | 기본값 | 설명 |
|---|---|---|
| `keep-on-death` | `true` | 사망 시 방어구 유지 |
| `respect-vanishing-curse` | `true` | 소멸 저주 방어구는 사망 시 사라지게 둠 |
| `guard-enabled` | `true` | 소실 자동 복구 |
| `legit-window-ticks` | `5` | 직접 벗는 동작 등을 정상으로 인정하는 시간(틱) |
| `legit-commands` | clear 등 | 이 명령어 직후 5틱은 정상으로 인정 |
| `notify-ops` | `true` | 복구 시 접속 중인 OP 에게 알림 |
| `log-restores` | `true` | `restore.log` 기록 |

## 빌드

```
mvn package
```
`target/CH-ArmorHide.jar` 를 `plugins/` 에 넣으면 됩니다.
